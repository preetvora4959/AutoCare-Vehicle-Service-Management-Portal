# 🚗 AutoCare – Vehicle Service Management Portal

### 💻 College Academic Mini Project | Web Development with PHP

AutoCare is a web-based **Vehicle Service Management Portal** developed as a college academic project at **Marwadi University**. It provides an easy platform for customers to manage their vehicles, explore services, and book vehicle maintenance appointments.

---

## 🛠️ Technology Stack

- 🐘 Core PHP
- 🗄️ MySQL & MySQLi
- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🖥️ XAMPP

## ✨ Key Features

### 👤 Customer Module
- Customer Registration & Login
- Customer Dashboard
- Profile Management
- Vehicle Management
- Browse Available Services
- Book Vehicle Services
- Booking History & Status Tracking

### 🔐 Admin Module
- Admin Dashboard
- Customer Management
- Service Management
- Booking Management
- Update Booking Status
- Search and Manage Customer Details

## ⚙️ Installation & Setup

1. Install **XAMPP** on your system.
2. Copy the project folder into the `htdocs` directory.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create/import the database using `database.sql`.
6. Configure the database connection in `db.php` if required.
7. Open the project in your browser:

   `http://localhost/AutoCare-Core-PHP/`
